# Hanvietech

**AI security agents that protect your code and web services.**

Hanvietech is a technology company based in Anyang, Republic of Korea. We build security agents powered by AI services: Jikimi checks the code you are developing, Doumi tests the web services you run, and AI helps your team decide. We also build enterprise AI agents tailored to your business and advise on, design, develop, and implement information systems.
